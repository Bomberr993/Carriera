# Dal Vivaio

Gioco di carriera calcistica in stile manager: parti a 15 anni dal vivaio e arrivi fino alla stella mondiale.

Tutto è in un unico file (`index.html`), senza dipendenze. Il salvataggio usa il `localStorage` del browser, quindi la partita resta salvata sul tuo dispositivo e sul tuo indirizzo GitHub Pages.

## Pubblicarlo su GitHub Pages
1. Crea un repository su GitHub (per esempio `dal-vivaio`).
2. Carica `index.html` e `README.md` nella radice (Add file › Upload files).
3. Vai in Settings › Pages, scegli Source: Deploy from a branch, branch `main`, cartella `/ (root)`, poi Save.
4. Dopo circa un minuto il gioco è su `https://TUO-NOME.github.io/dal-vivaio/`.

Nota: il salvataggio è legato all'indirizzo. Se cambi indirizzo o svuoti i dati del browser, la partita non si ritrova.
